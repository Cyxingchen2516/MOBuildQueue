# MOBuildQueue

《心灵终结 3.3.6》（Mental Omega 3.3.6）的客户端插件。

## 功能

- 建筑页、防御页支持连续排队：连点图标即可排多个
- 图标上显示待建数量
- `Shift + 左键` 一次排 5 个

## 配置

```ini
[Features]
BuildQueue=1   ; 0 = 原版行为
```
## 安装

1. 需要先安装 [Syringe](https://github.com/Ares-Developers/Syringe)（心灵终结自带）。
2. 把本目录下的文件放进游戏根目录（`gamemd.exe` 所在目录）。
3. 启动游戏即可。删除文件即卸载。

## 说明

- 纯客户端插件：不修改游戏模拟数据、不发送指令，联机时对方无需安装。
